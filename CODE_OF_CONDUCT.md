# Code of Conduct

## Our standard

Contributors and maintainers must communicate respectfully, welcome good-faith questions, give actionable technical feedback, and protect private or security-sensitive information such as API keys, balances, and usage data.

Harassment, discrimination, threats, deliberate disruption, spam, fabricated engagement, credential exposure, and publishing another person's private information are not acceptable.

## Scope

This standard applies in issues, pull requests, discussions, reviews, and other project spaces, as well as when representing the project in public.

## Enforcement

Report conduct concerns privately to a repository maintainer when a private contact channel is available. If no private channel is available, open a minimal issue requesting private contact without including personal, security-sensitive, or identifying details.

Maintainers may edit or remove content, close contributions, or temporarily or permanently restrict participation when necessary to protect the community. Enforcement decisions should be proportionate, documented privately where appropriate, and avoid exposing reporters or affected people.
